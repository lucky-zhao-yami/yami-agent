# 流程概览

## 整体架构

亚米网下单流程采用**异步MQ架构**，主要分为以下几个阶段：

```
用户下单 → 订单预处理 → 资源预占 → 支付 → 订单落库 → 风控检测 → 仓库发货
```

## 核心服务

### EC 服务（C端）
- **EC-SO (订单服务)**: 处理C端用户下单请求
- **EC-SO-Job**: 消费MQ消息，执行订单落库
- **EC-Payment (支付服务)**: 处理支付和第三方支付回调
- **EC-Customer**: 用户服务，管理用户信息、积分、礼卡

### Central 服务（中台）
- **Central-SO**: 订单中心，统一管理订单状态和流转
- **Central-Payment**: 支付中心，统一支付流程管理
- **Central-Customer**: 用户中心，用户数据中台
- **Central-FP**: 风控中心，订单风险检测和人工审核
- **Central-RMA**: 退货退款管理
- **Central-Activity**: 活动营销中心
- **Central-Distributor**: 分销商管理

### 外部系统
- **WMS**: 仓库管理系统
- **第三方支付**: Stripe、Braintree、支付宝、微信支付、PayPal等
- **Avalara**: 税务计算和上报系统

## 技术特点

### 微服务架构
- 服务拆分清晰，职责明确
- 每个服务独立部署和扩展
- 通过MQ实现服务间解耦

### 异步 MQ 架构
- 使用 RabbitMQ 实现服务间异步通信
- 支持延时队列、死信队列
- 消息持久化，保证可靠性

### 预占资源模式
- 新流程采用预占库存、积分、优惠券等资源
- 支付成功后再扣减真实资源
- 超时未支付自动释放预占资源

### 多支付方式
- 支持信用卡、支付宝、微信支付、PayPal、Apple Pay 等
- 统一的支付接口，易于扩展新支付方式
- 支持多币种和汇率转换

### 风控体系
- 完整的订单风控检测和人工审核流程
- 多维度风险评估
- 实时风控决策

### 税务合规
- 集成 Avalara 税务系统
- 自动计算和上报税务信息
- 支持美国各州税务规则

## 流程版本控制

### V1 (老流程)
- 下单后直接落库
- 同步处理，性能较低
- 风险控制相对简单

### V2 (改进流程)
- 增加了更多校验
- 优化了部分性能
- 增强了异常处理

### V3 (新流程, flow_version=1.0)
- 预占资源模式
- 完全异步处理
- 完善的风控体系
- 更好的用户体验

## 关键配置

```properties
# 流程版本控制
order_flow_version = 1.0
flow_version_whitelist = 10000983,10000982,10004482,10000770,877666

# 订单超时配置
order_canceled_timeout = 600000  # 10分钟
order_seckill_canceled_timeout = 300000  # 5分钟

# 库存操作类型
INVENTORY_OPERATE_TYPE_CREATE = "create"      # 直接扣减
INVENTORY_OPERATE_TYPE_PREOCCUPY = "preoccupy"  # 预占
```
