## MCP & AI Agent

### [modelcontextprotocol/servers](/mnt/d/github-kb/servers)
官方 MCP 服务器集合 - 包含文件系统、GitHub、Slack 等多种 MCP 实现
- 技术栈：TypeScript、Python
- 适用场景：学习 MCP 协议实现、扩展 AI 工具能力

### [jlowin/fastmcp](/mnt/d/github-kb/fastmcp)
快速构建 MCP 服务器的 Python 框架
- 技术栈：Python
- 适用场景：快速开发自定义 MCP 工具

### [moltbot/moltbot](/mnt/d/github-kb/moltbot)
个人 AI 助手（原 clawdbot）- 支持任意操作系统和平台
- 技术栈：TypeScript
- 适用场景：本地 AI 助手、多平台集成、Skills 扩展

### [microsoft/agent-framework](/mnt/d/github-kb/agent-framework)
微软统一 AI Agent 框架（Semantic Kernel + AutoGen 合并版）- 构建、编排和部署 AI Agent 及多 Agent 工作流
- 技术栈：Python 52%, C# 43%, TypeScript 4%
- 适用场景：多 Agent 编排（Sequential/Concurrent/Handoff/GroupChat/Magentic）、Graph-based Workflow、工具调用、MCP 集成、生产级 Agent 部署
