# 产品概述

## 项目名称
Yamibuy 微服务集群 - 亚米网电商平台后端服务

## 产品定位
这是一个基于微服务架构的电商平台后端系统，为亚米网（Yamibuy）提供完整的电商业务支持。系统采用领域驱动设计，按业务领域划分为多个独立的微服务。

## 服务架构

### Central 服务集群（中央服务）
- **central-customer-service**: 客户管理服务，负责客户信息、账户管理
- **central-fp-service**: FP（Fulfillment Partner）服务，负责履约合作伙伴管理
- **central-rma-service**: RMA（退货授权）服务，负责退货退款流程管理
- **central-so-service**: 销售订单服务，负责订单全生命周期管理

### EC 服务集群（电商服务）
- **ec-customer-service**: EC客户服务，负责电商渠道客户管理
- **ec-payment-service**: 支付服务，负责支付处理和对账
- **ec-rma-service**: EC退货服务，负责电商渠道退货管理
- **ec-so-service**: EC销售订单服务，负责电商渠道订单处理

### Public 公共模块
- **public/central/purchase**: Central 采购工具库
- **public/ec/purchase**: EC 采购工具库
- 提供跨服务的公共功能和工具类

## 核心业务能力
- **客户管理**: 客户注册、认证、信息管理、会员体系
- **订单管理**: 订单创建、支付、发货、取消、退款全流程
- **支付集成**: 多种支付方式支持（PayPal、信用卡等）
- **物流追踪**: 集成第三方物流服务，提供实时物流信息
- **退货管理**: 退货申请、审核、退款处理
- **税务计算**: 集成税务计算服务，支持跨境电商税务合规
- **营销活动**: 优惠券、礼品卡、积分、拼团等营销功能
- **定时任务**: 订单自动处理、数据同步、报表生成等后台任务
- **多语言支持**: 支持中文（简繁体）、英文、日文、韩文

## 业务场景
- B2C 电商订单处理
- B2B 批量订单管理
- 跨境电商物流追踪
- 多仓库订单分发
- 退款退货处理
- 财务对账结算
- 客户关系管理
- 营销活动管理

## 技术特点
- 微服务架构，服务独立部署
- 基于 Spring Cloud 的服务治理
- 使用 Apollo 配置中心统一管理配置
- 使用 RabbitMQ 实现服务间异步通信
- 使用 Redis 提供缓存和分布式锁
- 使用 XXL-Job 进行分布式任务调度
- Docker 容器化部署
