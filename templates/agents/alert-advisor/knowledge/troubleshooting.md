# 故障排查手册

## 常见告警场景

### 1. 订单量下降

**可能原因**：
- 支付渠道故障
- 促销活动结束
- 网站/APP 故障
- 第三方服务异常（物流、税务）
- 正常波动（节假日、时区）

**排查步骤**：
1. 确认下降幅度和时间点
2. 检查支付成功率
3. 检查各渠道订单分布
4. 查看错误日志

**验证 SQL**：
```sql
-- 按小时统计订单量
SELECT FROM_UNIXTIME(add_time, '%H:00') as hour, COUNT(*) as cnt
FROM xysc_order_info WHERE order_id BETWEEN {start} AND {end}
GROUP BY hour ORDER BY hour;

-- 支付状态分布
SELECT pay_status, COUNT(*) as cnt
FROM xysc_order_info WHERE order_id BETWEEN {start} AND {end}
GROUP BY pay_status;
```

### 2. 支付失败率上升

**可能原因**：
- 支付网关故障
- 风控规则误杀
- 用户支付信息问题
- 网络超时

**排查步骤**：
1. 检查各支付方式失败率
2. 查看失败错误码分布
3. 确认是否特定用户群体

### 3. 接口响应时间上升

**可能原因**：
- 数据库慢查询
- 缓存失效
- 第三方服务响应慢
- 流量突增

**排查步骤**：
1. 检查数据库慢查询日志
2. 检查 Redis 命中率
3. 检查外部服务调用耗时

### 4. 错误率上升

**可能原因**：
- 代码 Bug（新发布）
- 依赖服务故障
- 数据异常
- 配置错误

**排查步骤**：
1. 确认错误类型和堆栈
2. 检查最近发布记录
3. 检查依赖服务状态
